# Junction submission checklist

**Complete the form and click Submit Final before Sunday 15 November 2026,
10:00 Helsinki (08:00 UTC).** All copy, links, the recorded demo and the
presentation need to be prepared and checked before then. Leave time for the
upload and final review; **Save Draft does not complete the final submission**.
This deadline comes from the repository's [event schedule](../AI%20overview.md#event-deadlines-and-submission).

The draft below records the form contents supplied on 14 November. Checkboxes
mean reviewed and ready for submission; the existing text still needs review.
Fields marked **required** have an asterisk in the form. Prepare the remaining
materials too, or explicitly decide which optional fields do not apply.

## Form fields and materials

- [ ] **Project Name — required, max 30 characters.** Current draft: `Cheap Drive`.
- [ ] **Punchline — required, max 200 characters.** A concise one-liner capturing
  the project. Current draft: `Wroom Wroom.`
- [ ] **Description — required, max 5,000 characters; Markdown supported.**
  Current draft: `Model which maximizes shareholder value by moving cars by paying freelancers.`
  Review and expand this into a detailed description of what we built.
- [ ] **Challenge Picker — required.** Select and confirm `Spread`.
- [ ] **Project Demo.** Prepare a working project URL where judges can experience
  the project; check that they can access it.
- [ ] **Source Code.** Prepare the repository URL and verify judges can access
  the submitted code.
- [ ] **Video.** Record the demo, upload it to YouTube, Loom or another suitable
  host, and check the presentation link and viewing permissions.
- [ ] **Other Link.** Prepare any relevant supporting link, or mark it as not
  applicable during review.
- [ ] **Presentation.** Create and upload the final presentation. Accepted formats:
  **PDF, PPTX, PPT, ODP or KEY; maximum 20 MB**. The documented challenge guidance
  recommends 5–10 slides or a short video.
- [ ] **Tech Challenge Participation.** Review the available tech challenges and
  select any that apply; confirm if none apply.
- [ ] **Spread submission hash.** Obtain the hash from the team page and include
  it in the Junction submission as required by the documented challenge guidance.

## Final review before the deadline

- [ ] Review all copy, challenge selections, links and uploaded files together.
- [ ] Confirm the submission includes the Spread hash, code link and presentation
  materials described in the [submission guidance](../AI%20overview.md#event-deadlines-and-submission).
- [ ] Save the draft while preparing, then click **Submit Final** before the
  deadline and verify the platform confirms submission.
